# 适配指南：芯片/硬件制造类

**适用行业**：存储芯片、功率半导体、模拟芯片、射频芯片、MEMS 传感器、CIS 图像传感器、固态电池、显示面板等

**基本可直接套用主框架**，以下是需要注意的调整点。

## 技术路线部分

**"技术路线"的含义**：器件结构、材料体系、工艺路线。

典型的分类维度：
- 按器件原理（如存储的 DRAM/Flash/MRAM，功率器件的 Si/SiC/GaN）
- 按结构（2D vs 3D、平面 vs 垂直）
- 按材料体系
- 按工艺路线（如电池的干法 vs 湿法电极）

**关键参数**通常包括：性能指标、密度/功率密度、成本、可靠性/寿命、工作温度范围、良率。

**限制因素的三种本质**在这类行业尤其清晰：
- 物理极限：如 DRAM 电容微缩、SRAM 面积微缩墙
- 工程难题：如高深宽比刻蚀、材料一致性
- 经济性：如 3D XPoint 缺乏规模效应

## 产业链部分

必须重点展开：

**上游设备**：这往往是最大的卡脖子点。要区分：
- 哪些设备是**不可绕开的硬约束**（如 EUV 光刻机——ASML 全球独家，涉及全球数千家供应商，无替代方案）
- 哪些可以通过**技术路径变通**（如用串堆叠绕开单次超高深宽比刻蚀）

这个区分直接决定国产化前景判断。

**上游材料**：硅片/衬底、光刻胶、电子特气、CMP 材料、靶材、封装材料。每项给出国产化率和国内代表企业。

**制造模式**：必须讲清 IDM / Fabless+Foundry 的差异及其对投资门槛的影响。
- IDM 模式（存储、功率器件常见）：资金门槛百亿到千亿级，初创企业基本无法进入
- Fabless 模式（模拟、射频常见）：资金门槛数亿级，初创企业可进入

**这一点直接决定了"哪些环节一级市场投得进去"**，是第七部分投资判断的基础。

**封装测试**：如果先进封装在本行业有特殊重要性（如 HBM、Chiplet），要单独展开，用对比表讲清传统封装与先进封装的区别。

## 竞争格局部分

**代差判断维度**：制程节点 + 产品规格 + 量产时间差 + 良率成本 + 产能规模。

注意 **制程节点命名可能是营销手段**（如 DRAM 的 1α/1β/1γ 不对应真实物理尺寸，不同厂商命名也不可直接横比）。这本身应该作为"最容易理解错的地方"之一写进报告。

**必须提示的盲区**：良率和单位成本是企业核心机密，几乎无公开数据，这是代差判断的最大盲区。

## 市场部分

**高端/中低端划分标准**通常是：
- 性能规格（速率、容量、功率等级）
- **认证等级**：商规（0~70℃）/ 工规（-40~85℃）/ **车规（AEC-Q100，-40~125℃）** / 军规
- 制程节点
- 客户类型（消费 / 工业 / 汽车 / 数据中心）

**车规认证是关键分水岭**。AEC-Q100 认证周期通常 1-2 年，通过后客户绑定期长达十年。这既是壁垒也是机会——国产企业往往在消费级已追平，真正的战场在车规级。

## 周期性

这类行业通常有**强周期性**（3-4 年一轮）。原因：产品高度标准化（类似大宗商品）+ 产能建设周期长（2-3 年）→ 供需错配被放大。

第二部分要讲清当前在周期什么位置，第七部分要有"周期错位"投资逻辑。

## 投资判断的典型结论

这类行业往往会得出这样的结构性判断（要根据实际调研验证，不要直接照抄）：

1. **核心制造环节初创企业进不去**（资金门槛过高），一级机会主要在配套环节
2. **越是资本密集、依赖先进设备的环节，代差越大**——本质是设备可得性问题而非人才问题
3. **越是设计驱动、Fabless 的环节，代差越小甚至追平**
4. **头部扩产会确定性地拉动上游需求**，"卖铲人"逻辑确定性最高
