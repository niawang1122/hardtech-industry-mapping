## 第一部分：行业概览与产业链全景

### 1.1 这个行业是做什么的

用一两段话讲清它在整个技术体系中的位置和作用，帮读者建立直觉。

如果行业内部有层次结构（如存储的速度-容量金字塔、算力的分层、光通信的距离分层），**用 ASCII 图示或结构化方式画出来**——一张图胜过三段文字。

同时解释理解本行业必须知道的基础单位和概念（如 ns/μs/ms 的换算、bit 与 Byte 的区别）。这些看似基础，但非科班读者卡在这里就读不下去。

### 1.2 产业链全景

表格呈现，列：环节 / 主要内容 / 代表企业 / 中国国产化率或自主化程度。

环节至少分：上游材料、上游设备、中游核心制造或开发、中游封装/工程化、下游模组或系统、下游终端应用。

表格下方对表中出现的关键名词做解释（如 IDM、Fabless、Foundry 的模式差异）。

### 1.3 主要产品/技术分类

表格：类别 / 细分 / 功能定位 / 市场规模量级 / 成熟度。

对每个类别做通俗解释，尤其是那些名字相似但本质不同的（如 HDD 和 SSD、DRAM 和 SRAM）。

### 1.4 各环节投资机会速览

表格：方向 / 技术成熟度 / 市场增速 / 国产化率 / 一级投资活跃度 / 机会评级（★）。

这是全文的"地图"，读者看完这张表应该知道后面该重点看哪几节。

## 第二部分：行业发展

### 2.1 全球发展历程

时间线表格：时间 / 事件 / **意义**。

第三列是关键——不要只罗列事件，要说明每个事件为什么重要、改变了什么。

### 2.2 当前所处阶段

- 这个行业有周期性吗？周期长度多少？当前在周期什么位置？
- 核心驱动力是什么？
- **用可验证的数据支撑**：价格走势、产能利用率、龙头业绩、出货量等

### 2.3 未来发展展望

必须分开呈现，且分歧部分不可省略：

**普遍共识观点**：表格列出观点 / 依据 / 来源

**分歧或不同观点**：表格列出分歧点 / 观点A / 观点B

如果行业尚未形成共识，明确写"目前没有共识"，并说明这类预测的历史准确率通常不高，建议作为风险因素而非决策依据。

### 2.4 中国发展情况

- 发展阶段划分表（萌芽期/突破期/受阻期/加速期之类，按实际情况命名）
- 政策支持（具体政策名称、目标数字、资金规模）
- 外部限制及应对（如有制裁、出口管制、技术封锁）
- 企业层面的应对策略（技术路径绕行、供应链国产化、跳代研发等）

## 第三部分：技术路线全景（重点）

**这是全文篇幅最大的部分。** 后面所有分析都建立在这部分之上。

具体的表达方法见 `explanation-craft.md`，这里只讲结构。

### 3.0 前置概念

讲清理解本行业技术必须掌握的 2-4 个基础概念。每个概念也用"小白版 + 专业版"两层讲。

判断标准：如果不懂这个概念，后面的技术原理就完全看不懂——那它就是前置概念。

### 3.1 ~ 3.n 逐条技术路线

**分类组织**：先按大类分组（如易失性/非易失性、主流/新兴），再逐条展开。

每条路线的固定结构：

```
### 3.x.y 路线名称（英文全称，中文名）

【名词解释】（如果路线名称本身包含需要解释的词）

#### 【第一层：小白版】
生活化比喻 + 具体例子

#### 【第二层：专业版】
- 核心机制（详细展开到子步骤）
- 关键参数表（参数 / 典型值 / 说明）
- 世代演进表（如适用）
- 适用边界（适合什么、不适合什么）
- 常见误解澄清（❌/✅ 格式，3-5条）

#### 【限制因素与解决思路】
表格：限制因素 / 具体表现（专业） / 通俗理解 / 解决方案 / 可行性
```

**限制因素的分类很重要**：要区分是**物理极限**、**工程难题**还是**经济性问题**。三者的可突破性完全不同——物理极限几乎不可能突破，工程难题会随时间和投入解决，经济性问题取决于规模效应能否形成。这个区分直接决定投资判断。

**篇幅分配**：与市场占比、重要性正相关。主流路线详写，小众路线简写。但**尚未收敛的方向即使占比小也要写清楚**——那是早期投资的猎场。

### 3.x 架构/设计层面的创新方向

单独设节。即使尚未做出产品、仅有较好的设计架构或 idea，也要纳入。这是一级早期投资最值得关注的区域。

对每个方向说明：解决什么问题 / 核心思路 / 技术分层（如果概念常被混用，要严格区分）/ 产业界进展 / 适用边界 / 常见误解。

**特别注意**：这类方向最容易出现"理论值冒充实测值"。要明确指出该领域数据最容易被美化的位置，并给出追问方法。

### 3.y 技术路线综合对比（多张表）

**表1：核心性能对比**
维度包括：功能定位 / 存储或工作机制 / 各项关键指标 / 市场规模 / 成熟度

**表2：限制因素与解决路径对比**
列：技术 / 核心限制 / **限制的本质（物理/工程/经济）** / 最可能的解决路径 / 3-5年突破概率

**表3：投资价值综合对比**（最重要）
列：技术路线 / 技术突破可能性 / 市场规模 / 增速 / 初创企业进入难度 / **何时迎来显著增长（给年份区间）** / 稀缺性 / 综合投资价值 / 主要风险

表后给出 2-3 条核心判断结论，例如：
- 哪些环节初创企业根本进不去，为什么
- 哪些环节稀缺性最高
- 时间错配风险（新技术的增长时点 vs 基金存续期）

### 3.z 学习辅助三件套

放在第三部分末尾。

**① 小白说法与专业术语对应表**
把全文用过的所有比喻与对应术语一一对照。列：小白说法 / 专业术语 / 备注。

**② 最容易理解错的地方**
8-10 条，每条格式：
```
**N. "错误认知" —— 错在哪。**
正确理解是什么。**投资含义**：这个误解会导致什么判断失误，该怎么做。
```
重点覆盖在看 BP、听路演时容易被误导的点。

**③ 检查理解的三个问题**
3 道能真正检验理解深度的题，用 `<details><summary>参考答案（点击展开）</summary>...</details>` 折叠答案。

题目应贴近实际投资场景，例如"一家公司路演说 XXX，你该追问什么"，而不是知识点默写。

## 第四部分：市场规模与预测

### 4.0 先说清楚口径问题

**在给任何数字之前**，先解释为什么各机构数据差异大。常见原因：
- 是否包含下游成品（只算芯片 vs 含模组）
- 是否包含嵌入式部分
- 新品类如何归类（如 HBM 算不算在 DRAM 里）
- 统计年份与周期位置

然后说明本报告采用哪家作为基准及理由。

### 4.1 全球市场

**整体规模**：多机构对比表，列：来源 / 各年数据 / 中长期 / 口径说明 / **可信度（★）+ 评级理由**

明确给出"本报告建议采用的基准数据"。

对存在数量级分歧的数据（如某些新兴品类），单独说明分歧、分析原因、给出你的判断和依据。

**按技术路线拆分**：表格，含各路线规模、占比、趋势、来源。

### 4.2 按高端/中低端拆分

**先定义划分标准**：在这个行业的语境下，"高端"和"中低端"分别按什么划分？可能的维度：性能指标、容量、认证等级（车规/工规/商规）、客户类型、制程节点。

每个品类分别给表：分档 / 定义标准 / 典型产品 / 主要下游 / 毛利率 / 竞争格局 / 国产进展。

然后说明：**国产企业目前主要在哪一档、机会窗口在哪一档**。这是投资判断的关键。

如果没有权威机构按此口径统计（通常没有），明确说明这是估算，并给出估算依据。

### 4.3 中国市场

- 规模（多来源对比，说明口径差异）
- 增速与预测（多来源对比 + 你的判断）
- **自主化率现状与目标**（这往往比市场总规模更重要——它是国产企业的实际增量来源）
- 一级市场投融资情况：事件数、金额、阶段分布、投资主体

## 第五部分：竞争格局

### 5.0 代差判断方法论

**在给出任何代差结论前**，先说明判断依据：

表格：判断维度 / 说明 / 数据可得性

典型维度：产品规格（可得）、量产时间差（可得）、制程节点（部分可得）、**良率与成本（几乎不可得）**、产能规模（部分可得）。

然后明确提示：本报告的代差判断主要基于可得数据，**实际竞争力差距可能大于结论**，因为良率和成本无法获知。这是评估的最大盲区。

这一节看似是"免责"，实际上是让读者知道该在尽调中重点问什么。

### 5.1 全球市场份额

分品类给份额表。**整体统计数据优先于企业自我宣传数据**。

如果不同来源的份额数据口径不一（按出货量/按收入/按产能分配），明确指出并说明建议采用哪个及理由。

### 5.2 国际龙头企业

每家一张卡片表格，维度：
- 上市信息（是否上市、何时、代码）
- 创立时间与团队背景
- 技术路线及最新进展
- 主要产品及关键指标
- 主要客户及占比（如有；没有就写"未披露"）
- 投融资与估值
- 盈利情况
- **核心竞争壁垒**（这一条最重要——说清它凭什么领先）

### 5.3 国内企业——已上市

同样的卡片维度，加上**与国际龙头的代差分析**。

代差分析要写清判断依据，分维度列出，例如：
```
①产品规格：xxx → 此维度差距很小
②量产时间差：xxx → 时间差约2-3年
③制程节点：xxx → 差1-2代，且xxx是硬约束
④良率/成本：无公开数据，是最大盲区
综合判断：约差X代（约Y年）
```

不重要的公司可以用简表批量呈现。

### 5.4 国内企业——未上市

**要尽量多和全。** 同样维度 + 融资轮次/估值 + 代差分析。

**必须包括尚未量产、仅有较好设计架构或 idea 的早期公司**，注明所处阶段。

如果公开信息不足（早期公司通常如此），**明确说明"未能获取"并建议获取渠道**（FA机构、产业园区、高校技术转移办公室、顶会中国作者名单等），不要编造。

企业自述信息（"全球唯一""行业首创"）要标注为企业自述，建议交叉验证。

### 5.5 代差汇总表

列：维度 / 国际龙头 / 中国头部 / **代差判断（差几代、约几年）** / 判断依据可靠度

表后给出核心结论。通常会呈现出规律，例如：
- 越是资本密集、依赖先进设备的环节，代差越大（本质是设备可得性问题）
- 越是设计驱动、Fabless 模式的环节，代差越小
- 越是全球都处于早期的新方向，中国越有机会

## 第六部分：产业链拆解

### 6.1 上游——原材料

表格：材料 / **用途的通俗解释** / 国际主要供应商 / 国产化率 / 国内代表企业

"用途"一列不能只写专业名词，要说清这东西是干什么用的。

### 6.2 上游——核心设备

同上结构。对每类设备用一句通俗的话说清它的作用（"芯片制造的照相机""雕刻刀""体检仪"）。

**特别标注不可绕开的硬约束**——哪些环节是无论如何都绕不过去的（如 EUV 光刻机），哪些是可以通过技术路径变通的（如串堆叠绕开高深宽比刻蚀）。这个区分对判断国产化前景至关重要。

### 6.4 中游——封装测试/工程化

## 第七部分：一级投资机会判断与投资思路

### 7.1 宏观投资主线

通常包括：国产替代、新需求驱动的增量、新兴技术早期窗口、**稀缺性**。

每条给出：核心逻辑 / 确定性 / 时间窗口 / 适合的项目阶段。

**"稀缺性"逻辑必须展开**，因为早期项目往往没有收入、没有客户、甚至没有产品，此时唯一可评估的就是 idea 和团队的稀缺性。要说明稀缺性可以从哪几个层面判断：

- 技术路线稀缺（全球有几家在做？）
- 团队稀缺（这个组合全国有几个？关键人能否替代？）
- 资产稀缺（是否有难以复制的物理资产，如中试线、专用设备？）
- 窗口稀缺（机会窗口多长？错过还有没有？）

**并且必须给反面警示**：稀缺不等于有价值。要举反例（如 Optane 技术上全球独此一家，但商业失败）。稀缺性必须叠加"生态位判断"才成立。

### 7.2 各细分方向机会评估表

列：方向 / 阶段 / 市场规模 / 增速 / 技术突破可能 / 初创进入难度 / 显著增长时点 / 稀缺性 / 综合投资价值 / 主要风险

### 7.3 早期项目尽调清单

**必须是可执行的**——具体该问什么问题，而不是"要考察团队"这种空话。

分五块：

**① 团队（权重最高）**
- 技术出身：注意区分"在大厂待过"和"在大厂负责过关键模块"
- 学术背景：本行业的顶会是哪些？有没有第一作者论文？
- **交付记录**：这个团队以前完整地做出并量产过产品吗？从论文到能卖钱之间隔着巨大鸿沟
- 团队完整性：本行业需要哪几类人才？是否齐全？
- 关键人风险

**② 设计架构/idea 的独特性与前瞻性**
- 解决的是不是真痛点（行业公认的问题 vs 自己想象的需求）
- 独特性验证：全球有几个团队在做？如果很多人做，凭什么是你赢？**如果没人做，为什么？**（后者要警惕——可能是别人试过发现不行）
- 专利布局及被卡风险
- **技术路线的自主性**（对中国项目尤其关键——是否依赖被管制的设备/技术？）
- 可演进性

**③ 技术壁垒与可验证性**
- 是否已有实物验证（流片/样机/demo）
- **测试条件的真实性**：明确指出该行业数据最容易被美化的位置，并给出追问方法
- 一致性和良率
- 可量产性

**④ 客户验证路径**
- 首批目标客户是谁（要具体公司名，不是"XX厂商"这种笼统说法）
- 客户的真实动机：是"性能更好"（弱动机）还是"没有替代方案"（强动机）
- 切换成本
- 验证周期（本行业不同等级认证各需多久？）

**⑤ 落地可行性与资金需求**
- 模式判断（重资产 vs 轻资产）及对应的资金量级
- "死亡谷"长度：从 demo 到量产到盈亏平衡还需几年几轮
- **退出路径**：必须在投资时就想清楚——后续轮次估值提升？被谁并购？还是 IPO（需要多少收入规模）？

### 7.4 投资思路总结

3-5 条**可执行的判断逻辑**，每条包含：核心判断 + 依据 + 具体的筛选或提问方法。

常见的有效逻辑框架：
- **"卖铲人"逻辑**：不投挖金子的（门槛太高），投卖铲子的（配套环节）
- **"弯道超车"逻辑**：在全球都处于早期的方向布局
- **"生态位"逻辑**：给出三个必答问题——你在替代谁？客户为什么非用你不可？这个窗口多长？
