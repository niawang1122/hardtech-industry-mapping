# 交付前质量自检清单

逐项核对。发现不合格项就回去修，不要交付后等用户指出。

## 一、名词解释（最容易失败的地方）

- [ ] 全文扫描所有**英文缩写**，确认每个首次出现时都有括号解释
- [ ] 全文扫描所有**中文专有名词**，确认非科班读者会愣一下的词都有解释
- [ ] 检查解释是否真的在"解释"——**只给英文全称和中文翻译不算解释**
- [ ] 附录术语表是否覆盖了全文出现的所有术语
- [ ] 术语表的"通俗解释"一列是否说清了"这是什么东西"

**自测方法**：随机抽 5 个术语，问自己"一个聪明的文科生看完这个解释，能向别人复述这是什么吗？"

## 二、技术部分（篇幅最大、权重最高）

- [ ] 有 3.0 前置概念节，讲清了理解本行业必须掌握的基础概念
- [ ] **每条**技术路线都有"小白版"
- [ ] 小白版的比喻是**可延展的**——能解释机制、优势、代价、限制，不只是解释"是什么"
- [ ] **每条**技术路线都有"专业版"，且包含：核心机制（展开到子步骤）、关键参数表、适用边界、常见误解
- [ ] **每条**技术路线都有"限制因素与解决思路"表
- [ ] 限制因素**区分了物理极限 / 工程难题 / 经济性问题**三种本质
- [ ] 有架构/设计层面创新方向的单独章节（覆盖仅有 idea 的早期方向）
- [ ] 篇幅分配与技术路线的重要性/占比正相关
- [ ] 有技术路线综合对比表（至少三张：性能对比、限制因素对比、投资价值对比）
- [ ] 投资价值对比表包含"**何时迎来显著增长**"的年份区间判断
- [ ] 投资价值对比表包含"初创企业进入难度"
- [ ] 表后给出了 2-3 条核心判断结论

## 三、学习辅助三件套

- [ ] 有小白说法与专业术语对应表，覆盖全文用过的所有比喻
- [ ] 有"最容易理解错的地方"，8-10 条
- [ ] 每条易错点都落到了"**投资含义**"（否则只是知识点，不是判断工具）
- [ ] 易错点覆盖了本行业数据最容易被美化的位置
- [ ] 有三道自测题，用 `<details>` 折叠答案
- [ ] 题目贴近实际投资场景（如"公司路演说X，你该追问什么"），不是知识点默写

## 四、市场部分

- [ ] 在给任何数字之前，先有 4.0 节说明口径差异问题
- [ ] 说明了本报告采用哪家作为基准及理由
- [ ] 每个市场数据都有来源标注
- [ ] 每个预测数据都有可信度评级（★）**和评级理由**
- [ ] 存在数量级分歧的数据已单独说明、分析原因、给出判断
- [ ] 引用预测数据时注意了**发布时间**，对可能失效的旧预测做了提示
- [ ] 有高端/中低端拆分，且**先定义了划分标准**
- [ ] 说明了国产企业目前在哪一档、机会窗口在哪一档
- [ ] 有中国市场规模、增速、预测
- [ ] 有自主化率现状与目标（这往往比市场总规模更重要）
- [ ] 有一级市场投融资情况（事件数、金额、阶段分布）
- [ ] 如果某项数据确实找不到，明确写了"未找到"而非编造

## 五、竞争格局

- [ ] 有 5.0 代差判断方法论节
- [ ] 方法论中明确列出了**哪些维度的数据拿不到**（尤其良率和成本）
- [ ] 明确提示了实际竞争力差距可能大于报告结论
- [ ] 份额数据优先采用第三方统计而非企业自我宣传
- [ ] 不同来源份额口径不一时，说明了差异并给出建议采用哪个
- [ ] 国际龙头企业卡片覆盖了全部要求维度，尤其"核心竞争壁垒"
- [ ] 已上市国内企业有代差分析
- [ ] **未上市国内企业尽量多和全**
- [ ] 包含了尚未量产、仅有 idea/架构的早期公司，并注明阶段
- [ ] 早期公司信息不足时，明确说明"未能获取"并建议了获取渠道
- [ ] 企业自述信息（"全球唯一"等）已标注为企业自述
- [ ] 有代差汇总表，含判断依据可靠度
- [ ] 汇总表后给出了核心结论（通常呈现出规律性）

## 六、产业链

- [ ] 上游材料和设备的"用途"一列是通俗解释，不是专业名词堆砌
- [ ] 明确区分了**不可绕开的硬约束** vs **可技术变通的环节**
- [ ] 说明了行业主导模式（IDM/Fabless/其他）及其对投资门槛的影响
- [ ] 如涉及"传统 vs 先进"的区分（如封装），用对比表讲清了区别
- [ ] 有国产化程度与卡脖子点总结表，按严重程度排序

## 七、投资部分

- [ ] 宏观主线包含"稀缺性"，且**展开说明了稀缺性的几个判断层面**
- [ ] 稀缺性部分给了**反面警示**（稀缺不等于有价值，附反例）
- [ ] 有各细分方向机会评估表
- [ ] 尽调清单是**可执行的**——具体该问什么问题，不是"要考察团队"这种空话
- [ ] 尽调清单明确指出了本行业数据最容易被美化的位置及追问方法
- [ ] 尽调清单包含退出路径的考量
- [ ] 投资思路是可执行的判断逻辑，每条含核心判断+依据+具体方法
- [ ] 风险提示包含"信息不对称风险"，指明了哪些关键指标拿不到
- [ ] 有按投资偏好的配置思路表，包含"建议规避"

## 八、诚实性（一票否决项）

- [ ] **全文没有杜撰的数据**
- [ ] 事实 / 笔者判断 / 传闻 三类内容已明确区分标注
- [ ] 矛盾数据全部列出并给出判断，没有"挑一个假装没分歧"
- [ ] 行业尚无定论处明确写了"目前没有共识"
- [ ] **有专节列出"本报告未能获取的信息"**，说明原因和建议获取渠道
- [ ] 免责声明覆盖了：不构成投资建议、预测不确定性、估值传闻性质、代差未纳入良率成本、笔者判断与事实的区分、数据时效性

## 九、格式

- [ ] 每部分开头有"结论速览"，不超过 100 字
- [ ] 观点采用"先短语概括，再冒号展开"的形式
- [ ] 对比先分述再用表格汇总
- [ ] 有目录，且锚点可用
- [ ] 输出为 `.md` 文件并已用 present_files 交付

## 十、一致性（迭代时特别检查）

用户提出修改意见后：

- [ ] 不只改了被点名的地方，而是**全文扫描了同类问题**
- [ ] 各技术路线的原理深度是否一致（不能有的详有的略）
- [ ] 各企业卡片的维度是否一致
- [ ] 各表格的评级标准是否一致（★的含义前后统一）
