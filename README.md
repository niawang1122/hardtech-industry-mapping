# 硬科技行业 Mapping — Claude Skill

一个用于生成**一级市场投资级行业研究报告**的 Claude Skill。

面向硬科技行业（半导体、光电子、AI 模型、新能源、量子计算等），产出覆盖产业链全景、技术路线深度拆解、市场规模、竞争格局与代差分析、早期投资机会判断的完整 mapping 报告。

## 这个 Skill 解决什么问题

投资人看不懂技术，就无法判断项目。市面上的行业报告要么全是"前景广阔、潜力巨大"的空话，要么直接堆砌术语让非科班读者第二段就放弃。

这个 Skill 的核心方法是**双层解释**——同一个技术讲两遍：先用可延展的生活化比喻建立物理直觉，再用准确术语给出专业框架。目标是让读者能在路演现场判断一个技术故事是否成立。

## 特点

**技术优先**：技术路线部分是全文篇幅最大的部分。市场、竞争格局、投资判断都建立在技术理解之上。

**名词必须解释而非翻译**：`浮栅晶体管（Floating Gate Transistor）` 不算解释。要说清"在栅极和沟道之间额外插入一层四周被绝缘层完全包围、不与任何电路相连的导电材料，电子被困在里面从而断电也不丢数据"。中文专有名词同样如此。

**限制因素分三种本质**：物理极限 / 工程难题 / 经济性问题。三者可突破性完全不同——技术上一切正常但商业失败的项目，通常死于第三类。

**数据诚实**：数据有分歧就全部列出并给可信度评级，没找到就说没找到，尚无定论就说没有共识。报告末尾必须有专节列出"未能获取的信息"。

**代差判断透明**：明确说明判断依据，以及**哪些数据拿不到**（良率、成本几乎无公开数据）——这是在告诉读者尽调时该重点问什么。

**四类行业适配**：不同硬科技行业的产业形态差异很大，硬套框架会得出错误结论。Skill 内置四份适配指南。

## 报告结构

| 部分 | 内容 |
|---|---|
| 一、行业概览与产业链 | 行业定位、产业链全景、产品分类、机会速览 |
| 二、行业发展 | 历史时间线、当前阶段、未来展望（含分歧）、中国情况 |
| **三、技术路线全景** | **前置概念 + 逐条路线双层解释 + 限制因素 + 对比表 + 学习辅助三件套** |
| 四、市场规模与预测 | 口径说明、全球、高端/中低端拆分、中国市场 |
| 五、竞争格局 | 代差方法论、份额、企业卡片（含未上市）、代差汇总 |
| 六、产业链拆解 | 上中下游、国产化程度、卡脖子点 |
| 七、投资机会与思路 | 宏观主线、细分评估、尽调清单、投资逻辑、风险 |
| 附录 | 术语表、分级来源、未获取信息 |

技术部分末尾的**学习辅助三件套**：
1. 小白说法与专业术语对应表
2. 最容易理解错的地方（每条落到"投资含义"）
3. 三道自测题（贴近实际投资场景，如"公司路演说 X，你该追问什么"）

## 行业类型适配

| 类型 | 例子 | 关键调整 |
|---|---|---|
| 芯片/硬件制造 | 存储、功率半导体、MEMS、电池 | 区分硬约束设备 vs 可变通路径；IDM/Fabless 决定投资门槛 |
| 光学/光电子 | 光计算、硅光、激光雷达、光模块 | 增加光电混合封装环节（常被忽视的真实瓶颈）；未商业化方向不硬凑市场数字 |
| AI 算法/模型 | 世界模型、具身智能、多模态 | 产业链重定义；代差极不稳定；新增"被大厂覆盖"风险 |
| 系统/设备集成 | 量子计算、核聚变、手术机器人 | 用 TRL 框架；增加"核心分系统"层级；重点分析时间跨度与基金存续期错配 |

## 使用方式

### 在 Claude.ai / Claude Desktop

上传 `hardtech-industry-mapping.skill` 文件，点击 Save skill 安装。

### 在 Claude Code

将 `hardtech-industry-mapping/` 目录放入你的 skills 目录。

### 触发

安装后，用自然语言描述需求即可：

```
帮我把光模块行业做一个 mapping
研究一下世界模型这个方向
我想搞清楚固态电池的产业链和投资机会
```

Skill 会先输出提纲并提问确认，确认后再开始调研。**建议不要跳过提纲确认环节**——在花大量时间调研前先对齐颗粒度，能省掉大量返工。

## 注意事项

- 报告依赖联网搜索，请确保 Claude 的 web search 功能已开启
- 一份完整 mapping 通常需要 10-25 次搜索，耗时较长
- Skill 的输出是**研究材料，不是投资建议**。所有数据请在决策前自行核实
- 涉及未上市公司的估值信息多为市场传闻，Skill 会标注但无法验证真实性
